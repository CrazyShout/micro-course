# 参考书补充 / Reading companion

26 节既有微课增加连续解释、14 幅原创 SVG 示意图及 26 道双语自测。原有 50 节微课和 605 张卡片的编号、链接保持不变。

| 参考书 | 用途 | 阅读时的边界 |
| --- | --- | --- |
| Harrington, *Machine Learning in Action* (2012)；《机器学习实战》(2013) | 文本分类、逻辑回归、SVM、k-NN、回归、聚类、PCA/SVD；选读决策树和 AdaBoost | 两个语言版本属于同一著作；Python 2 / matrix 代码和部分简化表述需要对照当前模型 |
| Kurose & Ross, *Computer Networking: A Top-Down Approach*, 8th edition | 时延、队列、应用、传输、IP、路由、链路与完整网页访问 | 明确教学模型与真实协议实现的区别 |
| 上野宣，《图解 HTTP》(2014 中文版) | HTTP 缓存、会话、HTTPS 与协议协作的直觉 | 旧 SSL/TLS 图不能直接代表现代握手；缓存语义以正式规范核对 |

协议核对采用 [RFC 9111](https://www.rfc-editor.org/rfc/rfc9111.html)、[RFC 8446](https://www.rfc-editor.org/rfc/rfc8446.html)、[RFC 9114](https://www.rfc-editor.org/rfc/rfc9114.html)。每段补充有自己对应的章节和页码，不把书本补充误记为当前 Canvas 或 QE 的确认范围。

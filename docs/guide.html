CS5489 · Bilingual machine learning cards

这套牌组怎样配合学习 / Learning with this deck

适合从基础开始学习机器学习、需要用英文答题的学习者。整讲讲义沿老师顺序梳理内容，微课通过例子解释概念之间的联系；学懂后，用这里的双语题答回忆概念、公式条件和解题步骤。

For learners building machine-learning foundations and preparing to answer in English. Course notes follow the instructor’s sequence; micro-lessons explain connections through examples. Use the bilingual cards afterward to recall concepts, formula assumptions and solution steps.

当前课程与历史预习 / Current material and historical preview

当前材料包括Lecture1–5、Tutorial1–4及Assignment1–2相关方法。Extra Resources保留后续历史主题及深化内容，供按需预习。CNN完整内容等尚未由当前课件覆盖；QE范围以学校要求为准。

Current materials include Lectures 1–5, Tutorials 1–4 and methods for Assignments 1–2. Extra Resources contains historical topics and extensions for optional preparation. Full CNN coverage is still historical; the school defines the QE scope.

从哪里开始 / Getting started

从对应Lecture的讲义或微课开始，跟着完整例题计算，再独立做一道变式。文末列出少量首轮卡，按卡号在Markji查找；不熟悉的基础可先点补课入口。网页用于阅读与预览，Markji负责正式复习，两边进度独立。

Start with the relevant lecture notes or micro-lesson, work through an example, then solve a variation independently. Find the small first-pass set in Markji by card ID. Use prerequisite links when needed. The website supports reading and previews; Markji handles review, with separate progress.

课程安排在哪里看 / Where to find course information

评分、截止日期和提交清单在网站的“课程信息”栏。牌组中的来源与微课链接可帮助你回查定义、推导和原题。

Find grading, deadlines and submission checklists in Course information. Card sources and lesson links lead back to definitions, derivations and original questions.

怎样答卡片 / Answering the cards

先遮住答案，说出核心结论，再解释理由。计算题写出关键中间步骤；中文用于理解，随后尝试用英文独立回答。若只记得句子却解释不清，回到对应例题重做；编程题则需要实际运行。

Hide the answer, recall the conclusion and explain why. Show key steps in calculations. Use Chinese to understand, then try an independent English answer. If you remember a sentence but cannot explain it, redo its worked example; programming tasks require running code.

CS5222 · 计算机网络双语学习卡

CS5222 · Bilingual computer networking cards

进入本课程微课 / Open lessons · 查看卡片 / Open cards

这套牌组怎样配合学习 / Learning with this deck

通过网页访问、文件传输等情境理解网络，再用双语卡片复习术语、计算与机制。整讲讲义按老师Chapter顺序展开，微课跟踪分组、比特、ACK、窗口与路由状态，帮助你把各层联系起来。

Learn networking through web requests and file transfers, then review terminology, calculations and mechanisms with bilingual cards. Notes follow the instructor’s chapters; micro-lessons trace packets, bits, ACKs, windows and routing state to connect the layers.

当前课程与历史预习 / Current material and historical preview

当前材料包括Chapter1–2、Chapter3的part1–2、Tutorial1–5和Assignment1。Extra Resources保留后续传输、网络层与链路层等历史预习；完整连接管理与拥塞控制仍待当前课件。QE范围以学校要求为准。

Current materials include Chapters 1–2, Chapter 3 parts 1–2, Tutorials 1–5 and Assignment 1. Extra Resources contains historical material on later transport, network and link-layer topics. Full connection management and congestion control await current slides; the school defines QE scope.

从哪里开始 / Getting started

从对应Chapter的讲义或微课开始，画出路径或事件时间轴，再做配套Tutorial。文末列出少量首轮卡，按卡号在Markji查找。网页用于阅读和预览，正式复习在Markji完成，两边进度独立。

Start with the chapter notes or a micro-lesson, draw the path or event timeline, then attempt its tutorial. Find the small first-pass card set in Markji by ID. The website supports reading and previews; formal review happens in Markji, with separate progress.

课程安排在哪里看 / Where to find course information

评分、截止日期、提交清单与研究报告要求在网站的“课程信息”栏。卡片中的来源与微课链接帮助你回查协议约定、原图和计算过程。

Find grading, deadlines, submission checklists and research-report requirements in Course information. Card sources and lesson links help recover protocol assumptions, figures and calculations.

怎样答计算与机制题 / Answering calculation and mechanism questions

读清图、单位和完成事件，再动笔计算。回答机制题时说明谁发送什么、接收后怎样改变状态。改一个条件重算，并尝试用英文解释；遇到bit/byte、二进制或概率困难，可就近打开基础补课。

Read the figure, units and completion event before calculating. For mechanisms, explain who sends what and how receipt changes state. Recalculate after changing a condition, then explain in English. Use nearby foundation links for bits/bytes, binary or probability.

语言与范围

中文用于连续串讲；英文术语、英语摘要及中英双语题答帮助过渡到英文考试。“英语口述训练”展示英文摘要与题答，不是整篇中文讲解的逐句翻译。

本学期 Canvas 是课程范围基准。Extra Resources 来自往年资料，尚未确认为本学期或 QE 的完整范围。新增串讲、类比和练习是 AI 编写的学习辅助。

卡片中保留原图，以及资料文件名、页码或 Notebook 单元号。Canvas 和历史仓库的完整原文件留在本地资料库；公开的官方文档仍可通过出处链接访问。

参考书怎么读 / Reading companion

参考书补充位于相关微课的折叠区，适合在课内例子已经学懂后展开阅读。结合图示理解机制，尝试回答其中的双语自测；图示可点击放大。参考书的分类树和 AdaBoost 可按兴趣展开；当前 Lecture 4 的回归树与梯度提升见 ML31。

Machine Learning in Action（2012）与《机器学习实战》（2013）是同一著作的两个语言版本。网络部分参考 Computer Networking: A Top-Down Approach 第 8 版及《图解 HTTP》（2014）；HTTP 缓存、TLS 与 HTTP/3 的版本差异另核对 RFC 9111、8446、9114。新增段落有单独的书页定位，原始 PDF 留在本地。

Reading supplements add original diagrams and bilingual checks. Book chapters explain mechanisms; Canvas remains the assessment baseline. The English and Chinese editions of Machine Learning in Action are the same work. Legacy code and protocol descriptions are qualified where needed.
